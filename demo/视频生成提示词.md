# 视频生成提示词

## 使用方式
将角色设定图作为参考图上传到AI视频生成工具，配合以下提示词使用。

**重要：保持空间一致性 - 白骨精始终在悟空前方**

---

## 分镜1 (3秒) - 悟空背影，白骨精现身

**上传参考图:** 悟空角色设定卡 + 白骨精角色设定卡

```
远景镜头，悟空背对镜头站在前景中央。镜头从悟空背后拍摄，看向他的前方。

悟空身穿深色铠甲，金色毛发，手持金箍棒，静静站立。

在悟空前方远处的迷雾中，白骨精的身影缓缓浮现。她身穿飘逸的白衣，幽灵般的身姿在云雾中若隐若现。

云雾翻滚，白骨精逐渐清晰。

风格：暗黑中国神话，水墨元素，冷色调，电影级画面。
```

```

悟空身穿深色铠甲，金色毛发，正面面对镜头（同时也面对白骨精的方向）。他的金箍棒缓缓抬起，表情凶狠坚定，目光锐利。

镜头缓慢推进，聚焦悟空的战斗姿态。

背景中可以看到远处白骨精的身影。

```

## 总时长: 15秒 (3秒 × 5个分镜)

## 空间一致性说明

- 白骨精始终在悟空的**正前方**
- 悟空转身后直接面对白骨精
- 两人始终保持在同一视线轴上
